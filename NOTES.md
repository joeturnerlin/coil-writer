Parity uses 1280×800 CSS pixels, the same fixture and local fonts, no masks or post-capture color transforms. Both comparison processes receive --force-color-profile=srgb at launch, including the LaunchServices test app. On this Electron build, appending the switch inside main.ts did not reliably affect captures, so no ineffective production-side color workaround is retained. The harness controls the capture color space at process startup; application CSS colors remain unchanged. The gate is 0.05% differing pixels at pixelmatch threshold 0.01 with antialias exclusion, plus a maximum one-unit RGB-channel delta at every full-intensity cyan and amber reference pixel (over 300 samples per accent). This accommodates small rasterizer edge differences without permitting a uniform palette shift. Main-process provider requests remain mocked, and no test-only provider code ships in the app.
